# Cue for Mac

Cue turns your iPhone or iPad into a grid of pads that control your Mac: mute the mic in any call, flip the camera, tile windows, run a Terminal command, open apps, and more. Every pad shows the true state of what it controls.

**Download the Mac app** from the latest release on the right, open the DMG and drag Cue to Applications. It is signed and notarized by Apple.

Then install Cue on your iPhone or iPad (TestFlight for now), open it on the same Wi‑Fi, choose your Mac, and type the four‑digit code shown under Devices in Cue on the Mac. You only do that once.

## Requirements

- macOS 26 or later
- iOS or iPadOS 26 or later
- Both devices on the same Wi‑Fi

## Permissions the Mac app may ask for

- Accessibility: keyboard pads, window pads, in‑app buttons and menus
- Automation: dark mode, Terminal pads, media apps, browser tabs (asked per app, on first use)
- Screen Recording: screenshot pads only
