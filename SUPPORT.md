# Cue support

- **Pairing:** open Cue on the Mac, go to Devices, and type the four‑digit code into Cue on your device. Both must be on the same Wi‑Fi.
- **A pad is dimmed:** it needs something the Mac hasn't granted yet. Cue for Mac › Permissions explains which one. Call pads are only available while a meeting app is in front.
- **Nothing found when looking for a Mac:** check both devices share a network, and that Cue for Mac is running (its icon is in the menu bar).
- **Anything else:** open an issue at https://github.com/heyimjames/cue-releases/issues
